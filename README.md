# Burmese Kitchen Website

## Files
- `index.html` — home page
- `menu.html` — menu with your uploaded food photos
- `order.html` — validated demo order form with automatic total
- `about.html` — business information
- `contact.html` — contact/social placeholders
- `style.css` — burgundy, gold and cream responsive theme
- `script.js` — order total and validation
- `images/` — the 8 photos you uploaded

## GitHub Pages
1. Create a **Public** GitHub repository.
2. Upload all files and the entire `images` folder.
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch → main → /(root)**.
6. Save and wait for the Pages URL.

## Important
The prices are the example proposal prices supplied for Burmese Kitchen. The order form is a front-end demonstration only; it does not process real payments or save orders to a database.

## Your photos
The site uses the uploaded photos directly. The current mapping is: Mohinga, Shan Noodles, Burmese Curry Set, Laphet Thoke, Burmese Snacks, Family Meal Set, Catering Set, and the Burmese Kitchen logo.
